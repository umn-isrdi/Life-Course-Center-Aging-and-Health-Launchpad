# Life Course Center Aging and Health Launchpad
This repository within umn-isrdi provides the materials necessary for replicating the data analysis and data visualization from the [Life Course Center's](https://lcc.umn.edu/) [Aging and Health Launchpad](https://lcc.umn.edu/aging-and-health-launchpad) articles.
For each article, the following documents are provided:
1. A text file (.md) containing a link to the article on the Aging and Health Launchpad site; a description of the IPUMS data extract used to perform the data analysis, and a description of any other data used, if applicable; and citation information.
2. A json data extract definition, which can be used to submit a data extract request via the [IPUMS API](https://developer.ipums.org/docs/v2/apiprogram/).
3. A Stata .do file to replicate the data analysis and data visualization in the article.

**Notes**
1. Aging and Health Launchpad articles, analyses, and visualizations must be cited appropriately. Please cite both the article and the underlying data source(s), including IPUMS. Here is information on [citing IPUMS](https://www.ipums.org/about/citation).
2. IPUMS data can change over time. Most updates to IPUMS sites reflect the addition of new samples and occasionally changes to improve the quality of existing data. For this reason, changes to the underlying data since an Aging and Health Launchpad article was published may affect users' ability to exactly replicate the results presented in the article. Each IPUMS data collection has a revision history documenting any changes to the database. For example, here is the [IPUMS USA revision history](https://usa.ipums.org/usa-action/revisions).
3. Inquiries can be directed to either lcc@umn.edu or ipums@umn.edu.
